1. Create a folder named express-server.

2. Open the folder in VS Code.

3. Open the terminal and run:
mkdir express-server
cd express-server
npm init -y
npm install express

4. Create a file named server.js.

5. Write the following code:

const express = require("express");
const app = express();

app.get("/", (req, res) => {
    res.send("Hello, World!");
});

app.listen(1337, () => {
    console.log("Server running on port 1337");
});

6. Run the server:
node server.js

7. Open the browser and enter:
http://localhost:1337

8. Output:
Hello, World!
